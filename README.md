# JetBlack Pokédex

An unofficial, fan-made Pokédex for **Pokémon JetBlack**, a ROM hack of Pokémon Black created by EstrethAthema.

It lists all 649 Pokémon with the changes JetBlack makes to stats, abilities, evolutions, moves and learnsets, so you can look things up while you play without keeping the documentation open.

**Live site:** https://sevenskb.github.io/Jetblack-Pokedex/

## Features

- All 649 Pokémon with Gen V sprites
- Base stats shown against their vanilla values
- Abilities with descriptions, including abilities made standard by the hack
- Type defenses based on the Gen V type chart (no Fairy type)
- Best nature suggestions for every Pokémon and form, worked out from its JetBlack stats and level-up moves
- Wild encounter locations from the JetBlack location list, with levels, chances and ★ for rustling-grass, rippling-water and dust-cloud spots
- Areas section: every location with its wild Pokémon, static encounters, moved items and shops, searchable by area, Pokémon or item
- "Ask the Dex" helper that answers questions (locations, natures, moves, evolutions, weaknesses, items) straight from the JetBlack data, with no AI guessing
- Evolution lines with JetBlack's modified methods marked
- Level-up learnsets with type, category, power, PP, accuracy and a short description for each move
- Move changes (power, PP, accuracy, type, effect) shown next to the vanilla Gen V values
- TM/HM changes
- Alternate forms (Rotom, Deoxys, Wormadam and others) with their own sprites, types and stats
- Search by name, number, type, ability or move, with filters for generation and type

## About JetBlack

JetBlack was made by EstrethAthema to extend a playthrough of Pokémon Black. The main campaign stays limited to the original Unova Pokédex, while wild Pokémon, trainer rosters, stats, learnsets and moves are reworked. Everything in this Pokédex that describes the hack comes from the author's own documentation.

- Hackdex page: https://www.hackdex.app/hack/pokemon-jetblack
- Documentation: https://drive.google.com/drive/folders/1E2Ojixt45zFXQA7mWJA70vagqOLqRYe2?usp=sharing
- Original release thread: https://www.pokecommunity.com/threads/introducing-pokemon-jetblack-a-romhack-of-pokemon-black.535562/

If you want to play the hack, please download it from the author's links above.
